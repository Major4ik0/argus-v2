# Приложение 12 кафедры внутри АРГУСа

Эта папка переносится из основного репозитория приложения кафедры скриптом `tools/argus/release.py`.
Не правьте её здесь — правки пропадут при следующем переносе.

- Адрес: `/kafedra/` (API — `/kafedra/api`). Вход — кнопкой «Личный состав» в меню пользователя АРГУСа.
- Подключение: `backend/app/main.py` АРГУСа вызывает `kafedra.integration.argus.attach(app)`.
- База: та же, что у АРГУСа (`organaizer12`, его учётка из `DB_*`), наши таблицы — в схеме `kafedra`
  (таблицы АРГУСа в `public` не затрагиваются). Переопределяется `KAFEDRA_DATABASE_URL` и `KAFEDRA_DB_SCHEMA`.
  Миграции применяются при запуске.
- Учётные записи заводит администратор приложения кафедры по доменному логину; по паролю входит только администратор.
- Первый запуск: если в базе нет ни одной кафедры, загружается книга `/app/backend/data/kafedra/*.xlsm`, а главный
  администратор АРГУСа (`INITIAL_ADMIN`) становится администратором приложения. Контейнер без тома:
  `docker exec argus-app mkdir -p /app/backend/data/kafedra`,
  `docker cp книга.xlsm argus-app:/app/backend/data/kafedra/книга.xlsm`, `docker restart argus-app`.
