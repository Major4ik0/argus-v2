# InsightFace Models Directory (buffalo_l)

В эту директорию помещаются автономные модели ONNX Runtime:
1. `det_10g.onnx` — легковесный и точный детектор лиц SCRFD-10G (вход 640x640).
2. `w600k_r50.onnx` — экстрактор признаков ArcFace ResNet-50 / Glint360k (вход 112x112, выход 512-D L2-нормализованный вектор).

При наличии файлов система автоматически загружает их через ONNX Runtime CPUExecutionProvider.
При отсутствии файлов система работает в автономном режиме совместимости, сохраняя полную функциональность терминала, стриминга, базы данных и веб-интерфейса.
